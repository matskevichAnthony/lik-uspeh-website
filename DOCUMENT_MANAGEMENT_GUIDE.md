# 📋 Руководство по управлению документами

## Обзор системы

Система управления документами для сайта гимназии ЛИК-Успех состоит из **трех основных компонентов**:

1. **Нормативные документы** - общие документы школы
2. **Сведения об организации** - страницы с официальной информацией
3. **Документы для страниц** - файлы, привязанные к конкретным страницам организации

---

## 🎯 1. Нормативные документы

**Что это:** Общие документы школы (уставы, положения, приказы и т.д.)

**Где создавать:** Админ панель → **"Нормативные документы"**

**Поля:**
- **Заголовок** - название документа
- **Дата** - дата создания/утверждения
- **Описание** - краткое описание (необязательно)
- **Категория** - тип документа (Устав, Положения, Приказы, Инструкции, Другие)
- **Файл документа** - загрузка PDF/DOC файла
- **Содержание** - текстовое содержание в Markdown

**Пример использования:**
```
Заголовок: "Устав ЧНОУ Гимназия ЛИК-Успех"
Дата: 2024-01-15
Категория: Устав
Файл: ustav-2024.pdf
```

---

## 🏢 2. Сведения об организации

**Что это:** Официальные страницы с информацией об организации для соответствия законодательству

**Где создавать:** Админ панель → **"Сведения об организации"**

**Поля:**
- **Заголовок** - название страницы
- **Описание** - краткое описание
- **URL** - адрес страницы (например: `/svedeniya-ob-obrazovatelnoy-organizatsii/obrazovanie/`)
- **Последнее обновление** - дата последнего изменения
- **Вес (порядок)** - порядок в меню (меньше число = выше в списке)
- **Родительская страница** - если это подраздел
- **Настройки меню** - управление отображением в боковом меню
- **Содержание** - основной текст страницы в Markdown

**Стандартные страницы:**
- Основные сведения
- Структура и органы управления
- Документы
- Образование
- Образовательные стандарты
- Руководство. Педагогический состав
- Материально-техническое обеспечение
- И другие...

**Пример создания:**
```
Заголовок: "Материально-техническое обеспечение"
URL: /svedeniya-ob-obrazovatelnoy-organizatsii/materialno-tekhnicheskoe-obespechenie/
Родительская страница: Нет (основной раздел)
Вес: 60
```

---

## 📄 3. Документы для страниц

**Что это:** Файлы и ссылки, которые автоматически появляются на выбранных страницах организации

**Где создавать:** Админ панель → **"Документы для страниц"**

**Поля:**
- **Заголовок документа** - название файла/ссылки
- **Описание** - пояснение к документу
- **Тип документа** - файл или внешняя ссылка
- **Файл** - загрузка документа (если тип = файл)
- **Внешняя ссылка** - URL (если тип = ссылка)
- **Страницы организации** - выбор страниц где показать документ (множественный выбор!)
- **Категория документа** - тип для группировки
- **Дата документа** - дата создания
- **Размер файла** - например "2.5 MB"
- **Тип файла** - PDF, DOC, DOCX и т.д.

**Пример использования:**
```
Заголовок: "Учебный план 1-4 классы на 2024-2025 уч.год"
Тип документа: Загруженный файл
Файл: uchebnyy-plan-1-4-2024-2025.pdf
Страницы организации:
  ☑ Образование
  ☑ Учебные планы
Категория: Учебные планы
Размер файла: 1.2 MB
Тип файла: PDF
```

---

## 🔄 Как это работает

### Автоматическое связывание документов

1. **Создаете документ** в разделе "Документы для страниц"
2. **Выбираете страницы** где он должен появиться
3. **Документ автоматически появляется** на этих страницах в соответствующих разделах

### Группировка по категориям

Документы автоматически группируются по категориям на страницах:
- **Устав** → секция "Учредительные документы"
- **Учебные планы** → секция "Учебные планы"
- **Рабочие программы** → секция "Рабочие программы"
- И т.д.

---

## 📋 Рабочий процесс

### Для создания новой страницы организации:

1. Идите в **"Сведения об организации"**
2. Нажмите **"Создать"**
3. Заполните поля (особенно важен **URL**)
4. Сохраните
5. При необходимости добавьте документы через **"Документы для страниц"**

### Для добавления документов на существующие страницы:

1. Идите в **"Документы для страниц"**
2. Нажмите **"Создать"**
3. Загрузите файл или добавьте ссылку
4. **Выберите страницы** где документ должен появиться
5. Сохраните

---

## ⚠️ Важные моменты

1. **URL страниц** должны начинаться с `/svedeniya-ob-obrazovatelnoy-organizatsii/`
2. **Документы сохраняются** в папку `/static/documents/`
3. **Вес страницы** определяет порядок в меню (10, 20, 30...)
4. **Множественный выбор страниц** позволяет показать один документ на нескольких страницах
5. **Внешние ссылки** должны быть полными (https://example.com/doc.pdf)

## 🚀 Быстрый старт

1. **Запустите серверы:**
   ```bash
   npm run dev    # Hugo (порт 1314)
   npm run cms    # Decap CMS (порт 8081)
   ```

2. **Откройте админ-панель:** http://localhost:1314/admin/

3. **Создайте документ:**
   - Выберите "Документы для страниц"
   - Загрузите файл
   - Выберите страницы для отображения
   - Сохраните

4. **Проверьте результат** на сайте!
